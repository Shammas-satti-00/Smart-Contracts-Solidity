## 📝 Smart Contracts

Some contracts in this repository are simple examples designed to demonstrate individual Solidity concepts.

For example:

```solidity
// Simple Solidity example

pragma solidity ^0.8.0;

contract SimpleStorage {

    uint256 public number;

    function setNumber(uint256 _number) public {
        number = _number;
    }

    function getNumber() public view returns (uint256) {
        return number;
    }
}
```

The contracts become more complex as I learn new concepts and start combining them.
